# MYCELIUM — статическая версия

Каталог 39 грибов с фотографиями, интерактивными Three.js / React Three Fiber моделями, фильтрами, поиском и описаниями. Аккаунты и прогресс хранятся в localStorage этого браузера. Серверное API и PostgreSQL не нужны ни для сборки, ни для публикации.

## Локальный запуск

Нужен Node.js 22+.

```sh
npm ci
npm run dev
```

Открыть http://127.0.0.1:3000.

## Статическая сборка

```sh
npm run build
npm start
```

Готовые HTML, JS, фотографии и модели находятся в `out/`. Это полностью самостоятельный статический сайт. `npm start` запускает простой локальный сервер для просмотра `out/`, не backend приложения.

Для GitHub Pages проекта `mycelium` в PowerShell:

```powershell
$env:NEXT_PUBLIC_BASE_PATH = '/mycelium'
npm run build
npm start
```

Просмотр: http://127.0.0.1:3000/mycelium/.

## GitHub Pages

В репозитории `DayDayDay-ai/mycelium`: Settings → Pages → Build and deployment → Source: GitHub Actions. После загрузки изменений в main workflow `.github/workflows/pages.yml` собирает и публикует `out/`.

Адрес после успешной публикации: https://daydayday-ai.github.io/mycelium/.

## Аккаунты и прогресс

Регистрация: имя, ник дважды, пароль дважды. Ник: 3–30 символов латиницей, цифры и `_`, первый символ — буква. Регистр не учитывается. Пароль: от 4 символов, до 72 байт UTF-8. Вход: ник и пароль.

Уникальность ника действует только в этом браузере. Каждый аккаунт имеет отдельный прогресс; гостевые отметки можно перенести после входа. Пароли сохраняются как PBKDF2 SHA-256 хеши с отдельной случайной солью, 150 000 итераций. Пароли в открытом виде не сохраняются. Локальный профиль не является серверной авторизацией: данные принадлежат браузеру, не синхронизируются между устройствами и исчезают после очистки хранилища. Другой браузер или адрес сайта — отдельное хранилище.

## Содержание

Статический набор: `src/lib/mushrooms.json`. Фотографии: `public/photos/`. Лицензии и авторство: `src/lib/photo-credits.json`. Источники, региональные ограничения и особенности учебных 3D-моделей: `CONTENT.md`. Новое содержимое редактируется в JSON и публикуется повторной сборкой. Серверной админки нет.

## Проверки

```sh
npm test
npm run build
node scripts/verify-static.mjs
```

Для браузерного прогона нужен запущенный статический preview и Chrome. Переменная `STATIC_BASE_URL` позволяет задать адрес preview. Проверки используют отдельное тестовое хранилище браузера.
