# MYCELIUM

Рабочий образовательный MVP для изучения грибов: Next.js 16, TypeScript, React 19, Tailwind 4, компоненты shadcn/ui на Radix, PostgreSQL, Prisma 6, Zod и React Three Fiber / Three.js.

## Быстрый запуск

Нужен Node.js 22+. Команды выполняются в этой папке.

```sh
npm install
```

Скопируйте `.env.example` в `.env` (Windows PowerShell: `Copy-Item .env.example .env`). Далее поднимите PostgreSQL одним из способов:

**Без Docker, для локальной разработки**

```sh
npm run db:local
```

Оставьте этот терминал открытым. Это настоящий процесс PostgreSQL с постоянными данными в `work/postgres`, слушающий только `127.0.0.1:54329`. Пароль из примера предназначен исключительно для локальной разработки. На Windows используется относительный путь к каталогу данных для корректного запуска initdb. При остановке процесса файлы базы сохраняются.

**Docker**

```sh
docker compose up -d
```

**Существующий PostgreSQL / облачная база**

Укажите свой `DATABASE_URL` в `.env`. При необходимости добавьте `sslmode=require`. Приложение не использует JSON-файл или запасной массив вместо базы данных.

В другом терминале:

```sh
npm run db:generate
npm run db:setup
npm run dev
```

Откройте http://127.0.0.1:3000. Для production:

```sh
npm run build
npm start
```

## Миграции и seed

```sh
npx prisma migrate dev --name description_of_change
npm run db:migrate
npm run db:seed
npx prisma studio
```

`db:migrate` применяет сохранённые SQL migrations через `prisma migrate deploy`. `db:seed` устанавливает 39 видов, локальные фотографии и связанные пары двойников. Повторный seed обновляет справочные поля этих 39 видов из проверенного набора; изменения редактора в этих полях будут перезаписаны. Другие добавленные редактором виды, аккаунты и прогресс сохраняются. Неподтверждённые поля не показываются пользователю. Месяцы относятся к региону исходного справочника First Nature (Британия и Ирландия), а не ко всем странам. Источник указан в каждой карточке.

## Регистрация и вход

Регистрация: имя, уникальный ник латиницей дважды, пароль дважды. Ник: 3–30 символов, первый — буква, далее буквы, цифры и `_`; регистр не учитывается. Пароль: минимум 4 символа, максимум 72 байта UTF-8. Email не требуется. Вход: ник и пароль.

При миграции прежние аккаунты сохраняют ID, пароли и прогресс; их ник становится `user_` + ID аккаунта.

## Администратор

В `.env` задайте `ADMIN_USERNAME` и уникальный `ADMIN_PASSWORD` (не менее 4 символов), затем выполните `npm run db:seed`. Войдите в `/account` и откройте `/admin`. Известного общего пароля администратора в проекте нет. Обычная регистрация всегда создаёт роль USER.

Редактор создаёт и изменяет виды, скрывает их без удаления, меняет сезон, съедобность, токсичность, охранный и региональный статус сбора, редактирует признаки, добавляет двойников, загружает фото и модели. Фото: JPEG, PNG, WebP; модель: GLB или самостоятельный GLTF со встроенными ресурсами. Максимальный размер файла — 20 МБ. Загрузка проверяет тип, расширение и сигнатуру. Обложка и фотогалерея поддерживают локальные загрузки и HTTPS URL на `images.unsplash.com` / `upload.wikimedia.org`. Для иных доверенных источников обновите `next.config.ts` и валидацию в `src/lib/admin.ts`.

## Главный сценарий

Главная → «Начать изучать» → каталог → комбинированные фильтры → гриб → вращение и масштабирование 3D → признаки / сезон / двойники → READY → «Да, изучил» → отметка в каталоге и обновлённый прогресс.

- Гостевой прогресс хранится в `localStorage` под версионированным ключом `mycelium-progress-v1`.
- Аккаунт хранит прогресс в PostgreSQL. После регистрации и входа предлагается явный перенос гостевых отметок; объединение идемпотентно.
- Выход не смешивает данные аккаунта с гостевым прогрессом.
- Уровни: 0, 5, 10, 25, 50, 100. Процент рассчитывается по опубликованному каталогу; цель следующего уровня — по общей шкале.
- READY появляется при достижении последней секции, повторно для изученного вида не показывается. Материал можно повторить или сбросить отметку.
- Съедобность, токсичность, охранный статус и статус сбора — отдельные поля. У стартовых съедобных видов статус сбора REGIONAL, поскольку универсальное разрешение без страны/региона некорректно.

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/mushrooms` | Опубликованный каталог с поиском, фильтрами и сортировкой |
| GET | `/api/mushrooms/:slug` | Карточка, фото, регионы и двойники |
| GET | `/api/mushrooms/:slug/lookalikes` | Опубликованные похожие виды |
| GET | `/api/auth/me` | Текущий аккаунт |
| POST | `/api/auth/register`, `/api/auth/login`, `/api/auth/logout` | Регистрация, вход, выход |
| GET | `/api/progress` | Прогресс аккаунта |
| POST | `/api/progress` | Перенос массива `{ ids: string[] }` |
| POST | `/api/progress/:id/start`, `/studied`, `/reset` | Изменение статуса |
| GET / POST | `/api/admin/mushrooms` | Просмотр редактора / создание |
| PUT | `/api/admin/mushrooms/:id` | Редактирование |
| POST | `/api/admin/upload` | Загрузка файла администратором |

Пример: `/mushrooms?edibility=EDIBLE,CONDITIONAL&collection=REGIONAL&month=8&difficulty=2&sort=az&q=гриб`.

Параметры: `edibility`, `collection`, `month` (1–12), `season` (`spring`, `summer`, `autumn`, `winter`), `difficulty` (1–3), `habitat`, `progress` (`studied`, `unstarted`), `q`, `sort`. Группы соединяются AND, категории съедобности — OR. Сервер фильтрует прогресс авторизованного пользователя; гостевой прогресс фильтруется в браузере. URL восстанавливает фильтры при переходах, перезагрузке и использовании кнопки «Назад».

## Проверка

```sh
npm test
npm run build
npm audit
node --env-file=.env scripts/verify.mjs
```

Для браузерной проверки нужен Chrome; нестандартный путь задаётся переменной `CHROME_PATH`. Сервер и PostgreSQL должны быть запущены. Скрипт создаёт временных пользователей и запись гриба, проверяет guest → account sync, доступы, CSRF, CRUD редактора и upload, затем удаляет свои записи. Снимки desktop/mobile и итоговый JSON находятся в `verification/`.

## Перед публичным запуском

Карточки используют реальные локальные фотографии из iNaturalist и Wikimedia Commons: общественное достояние, CC0, CC BY или CC BY-SA. Авторство, лицензия и источник находятся под просмотром; полный манифест — `src/lib/photo-credits.json`. Сайт не обращается к внешнему API за содержимым: фотографии лежат в `public/photos`, сведения — в seed и PostgreSQL. Переключатель «Фото / 3D-модель» находится над просмотром. 3D — интерактивные учебные модели общей формы; редактор также поддерживает GLB. Они не являются точными диагностическими реконструкциями. Перед публичной публикацией содержание нужно проверить с микологом: источник и исследовательский статус наблюдения не дают 100% гарантии определения.

Источники, географические ограничения и правила наполнения описаны в `CONTENT.md`. Для повторного импорта лицензированных фото предусмотрен `node scripts/import-photos.mjs`; это отдельная служебная операция, не часть запуска сайта.

Для размещения на постоянном Node-сервере сохраните `public/uploads` на постоянном диске и настройте резервное копирование PostgreSQL. На бессерверном хостинге замените локальное файловое хранилище объектным (например, S3); файловая система там непостоянна. Укажите публичный HTTPS `APP_URL`, используйте уникальные пароли базы и HTTPS. Сессионные cookies: HttpOnly, SameSite=Lax и Secure при HTTPS. Пароли хешируются bcrypt, в БД хранится только SHA-256 случайного session token. Авторизация и роль проверяются в каждом защищённом API. Ограничение попыток входа пока хранится в памяти процесса; при нескольких экземплярах нужен общий rate limiter. Восстановление пароля не входит в этот MVP.

## Источники

Стартовые краткие признаки и сезоны проверены по карточкам [First Nature](https://www.first-nature.com/fungi/) и [Woodland Trust](https://www.woodlandtrust.org.uk/trees-woods-and-wildlife/fungi-and-lichens/). Точная ссылка сохраняется в БД для каждого вида. Неизвестные поля не заполнены вымышленными сведениями. Коллекционные статусы FORBIDDEN у токсичных видов — рекомендация не собирать, а не утверждение о конкретной правовой норме.

Проект использует зафиксированную Prisma 6.19; актуальные транзитивные `effect` и `deepmerge-ts` заданы через overrides для устранения известных advisory. Не обновляйте Prisma на следующую major без миграции конфигурации.
