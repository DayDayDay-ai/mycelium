# Проверка статической версии MYCELIUM

Проверено 5 октября 2026 года. Приложение собрано с output: export и базовым путём /mycelium. База остановлена; API, Prisma, серверные аккаунты и админка из опубликованной версии удалены.

- Статический каталог: 39 видов, фильтры и поиск сохраняются в URL.
- Фото, интерактивный WebGL и возврат в каталог после «Изучено» работают.
- Гостевой прогресс сохраняется после перезагрузки.
- Локальная регистрация с 4-символьным паролем, перенос гостевого прогресса, выход и вход проверены.
- Два локальных аккаунта имеют отдельный прогресс; вход не зависит от регистра ника, неверный пароль отклоняется.
- В localStorage нет открытого пароля; хеш PBKDF2 с отдельной солью проверен.
- Mobile 390×844: модель и регистрация работают, горизонтального переполнения нет.
- JavaScript ошибок: 0. API запросов: 0. Отсутствующих ресурсов: 0.
- Unit tests: 5 / 5.

Машиночитаемый результат: static-report.json. Скрипт: scripts/verify-static.mjs. Скриншоты: static-catalog.png, static-mobile.png, static-registration.png.

GitHub Actions workflow подготовлен; онлайн-публикация требует загрузки изменений в репозиторий и выбора GitHub Actions в Settings → Pages.

Локальный аккаунт относится только к этому браузеру и origin. При очистке хранилища данные исчезают; синхронизации между устройствами нет. 3D-модели учебные и не являются точными диагностическими реконструкциями.
